# 2dPig Pixel Office assets

Source: https://2dpig.itch.io/pixel-office

The original pack is released under CC0. The bundled `LICENSE.txt` is copied
from the downloaded archive.

- `office-assets.png`: sprite sheet used by the Splice office rooms
- `office-scene.png`: original large example scene kept as a visual reference

Splice uses cropped regions from the sprite sheet through CSS backgrounds. Do
not stretch the source pixels; render them with pixelated image sampling.
